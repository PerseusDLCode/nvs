* Where things stand

Working on citation resolution within Furness's commentary apparatus
for the Hypervariorum (NVS) King Lear edition. The task: resolve the
bare-colon =<SC>Name</SC>= citations in the annotation XML to actual
bibliography entries, without relying on regex — this requires real
syntactic/contextual judgment, which is itself a Schmidt Sciences–
relevant finding about Edge 2 vs. Edge 3 task classification
(documented in =concepts.org=).

The resolution table is built as a *cascade*, checking our own parsed
bibliography before reaching for external research:

- *Tier 0* — already resolvable from our own parsed bibliography.
  Single-play Lear editions (not excluded by Norris's "surplusage"
  rule, which only applies to complete-*Works* editions). E.g.
  Wright (150 occurrences → Clarendon Ed., 1875), Moberly (89 →
  Rugby Ed., 1871).
- *Tier 1* — needs real recall of 18th/19th-c. editing history but
  resolvable with moderate-to-high confidence (e.g. Verplanck →
  Gulian C. Verplanck's /Illustrated Shakespeare/, 1847).
- *Tier 2* — points back to bibliography rows we already parsed but
  hadn't cross-referenced (e.g. Davies → Dramatic Miscellanies, 1784,
  row 54 — flagged pending confirmation).
- *Tiers 3–5* — genuinely open/low-confidence: one-off citations that
  may not be Shakespeare scholarship at all (Sir Joshua Reynolds —
  the painter, almost certainly anecdotal; Dr Burney — probably a
  musical point; Wedgwood — probably etymological), OCR/tag-boundary
  artifacts to check against source (Beisly, "Hudson. Wright"), and
  name collisions (Clarke vs. Cowden Clarke).
