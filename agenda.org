Add a function =parse_inline_markup(text: str, parent: _Element) -> None=
to =src/hypervariorum/nvs/parsers.py=. It should:

1. Scan =text= for the five known inline tags (=B=, =I=, =SC=, =SUB=,
   =G=) using =re.split= or =re.finditer= over the pattern
   =<(B|I|SC|SUB|G)>(.*?)</(B|I|SC|SUB|G)>= with =re.DOTALL=.
   These tags do not nest in the corpus.
2. For each matched tag, append any preceding text as a text node or
   tail on the previous element, then append a =<hi rend="...">= child
   with the appropriate =rend= value:
   =B=→=bold=, =I=→=italic=, =SC=→=smallcaps=, =SUB=→=subscript=,
   =G=→=greek=.
3. Leave everything else — entities (=&lquo;=, =&mdash;=, etc.),
   punctuation, unrecognized tags — as plain text. Do not attempt
   to parse the raw content as XML.

Replace the two places in =ChunkConsolidator= where =.text= is
currently assigned to =<lemma>= and =<commentary>= elements with
calls to =parse_inline_markup=.

part doesn't match the comma-list lemma pattern (excludes that separate

to the last open annotation rather than starting a new one.
